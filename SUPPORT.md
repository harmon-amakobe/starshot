# Getting help

Starshot is built by one person with AI agents (D25). Answers come through GitHub, in
public, so the next person with the same question finds them.

| You want to | Go to |
|---|---|
| Ask how something works | GitHub Discussions, once the owner turns them on; until then, an issue |
| Report a bug | The "Bug report" issue form |
| Suggest a feature | The "Feature request" issue form |
| Propose a level on a real launch window | The "Level idea" issue form |
| Report a position or a timing that disagrees with NASA/JPL | The "Physics discrepancy" issue form |
| Report a security problem | Privately, as `SECURITY.md` describes; never in a public issue |
| Report a conduct problem | As `CODE_OF_CONDUCT.md` describes |
| Ask about the name or the logo | As `TRADEMARK.md` describes |

Before you open an issue, search the existing ones. A short report with steps, the
device and the browser gets an answer sooner than a long one without them.

There is no support by email or by private message, and no promised response time.
Issues are triaged as `CONTRIBUTING.md` describes.
